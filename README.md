# Foody — Restaurant Website

Foody is a modern and responsive restaurant website designed to showcase delicious meals, recipes, and restaurant content through an attractive and user-friendly interface.

## Features

- **Responsive Design:** Compatible with desktop, tablet, and mobile devices.
- **Modern UI:** Clean layout with an appealing restaurant-inspired design.
- **Recipe Sections:** Displays featured recipes and popular dishes.
- **Interactive Elements:** JavaScript-powered buttons and user interactions.
- **Food Categories:** Organizes dishes and recipes for easy browsing.
- **Visual Content:** Uses food photography to enhance the user experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Craft-Coders-Team/Foody.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Foody
   ```

3. Open `index.html` in your browser.

   You can also use the Live Server extension in Visual Studio Code for local development.
